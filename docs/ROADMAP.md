# VentureIQ: Product Roadmap

## Release 1.0 (Core Foundation) - Current Scope
- [x] Pure deterministic financial calculation engine with invariant validation.
- [x] Subscription & SaaS business model support.
- [x] Monthly customer movement bridge, MRR, ARR run rate, and margins.
- [x] Headcount and hiring plan integration with payroll burden and ramp timing.
- [x] Monthly cash flow reconciliation, net burn, and reserve-aware runway calculation.
- [x] Bounded reverse-planning engine with constrained optimization and infeasibility analysis.
- [x] Sensitivity analysis (1-variable, 2-variable, Tornado ranking).
- [x] Scenario comparison (Base, Optimistic, Downside, and Custom).
- [x] Interactive web dashboard with Recharts visualizations, scenario toggles, and Indian Rupee / Global currency support.
- [x] Multi-tenant organization scoping, JWT authentication, and model persistence.
- [x] CSV import with mapping and preview; CSV and PDF report exports.
- [x] Optional AI narrative explanation layer.

---

## Release 1.1 (Operational Enhancements)
- Cohort retention decay curves (power-law / logarithmic retention instead of static churn).
- Configurable payment collection delays (Days Sales Outstanding / receivable lag).
- Tiered pricing plans with distinct ARPU and churn profiles per customer tier.

---

## Release 2.0 (New Business Models)
- Marketplace model (Take-rates, GMV, buyer & seller acquisition funnels).
- Usage-based & transactional consumption models (credits, compute hours, payment volume fees).
- Direct integrations with Stripe, ChartMogul, and QuickBooks for automated historical sync.
